## Exercise Reflection

This exercise assesses practical skills that remain valuable when working with AI. I used AI to help scope the work, plan the folder structure, set up the environment, prepare documentation, and explain unfamiliar concepts. Building the application helped me better understand how the API client, commands, models, and database work together.

To improve the hiring process, I would keep the exercise small, provide a working starter project, and clearly outline the essential requirements and expected time commitment. This would help candidates focus on solving the problem. A brief feedback email afterwards would help candidates understand what they did well and where they could improve. Continuing to allow AI use with disclosure would also reflect how developers work today.
